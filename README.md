# google-calender-widget

An unofficial Google Calendar desktop widget for Windows, macOS and Linux. It sits on your desktop, stays out of the way, and shows your real calendar — built with Electron.

![Screenshot (78)](https://github.com/p32929/google-calender-widget/assets/6418354/43f8074d-2d81-47d8-aba6-982c9bf637f3)

### Tray menu
![Tray](https://github.com/user-attachments/assets/056e36ab-a86e-4987-b73d-dd58974313fa)

## Features

- **Your real Google Calendar** — logs into your own account, no third-party middleman
- **Dark mode** and an agenda view that stays readable
- **Tray menu** — show, hide, always-on-top and quit without hunting for the window
- **Remembers its position and size** between launches
- **Windows, macOS and Linux** builds from the same codebase

## How to install

Download the installer for your OS from the [latest release](https://github.com/p32929/google-calender-widget/releases/latest), install and run.

## How to use

1. Open the app
2. Login using Google
3. Done!

## Build from source

```bash
git clone https://github.com/p32929/google-calender-widget.git
cd google-calender-widget
npm install
npm start          # run in dev with auto-reload

npm run dist:win   # build a Windows installer
npm run dist:mac   # build for macOS
npm run dist:linux # build for Linux
```
